Simple DNA Analyzer

A beginner Python project that analyzes DNA sequences using basic Python concepts.

Features

- DNA Validation: Checks whether the sequence contains only valid DNA bases (A, T, G, C).
- Invalid Input Handling: Detects invalid characters and displays an error message.
- Empty Input Handling: Displays a message when no DNA sequence is entered.
- Sequence Length: Calculates the total number of bases.
- Base Counting: Counts A, T, G, and C individually.
- GC Percentage: Calculates the percentage of G and C bases in the sequence.
- Case-Insensitive Input: Accepts both uppercase and lowercase DNA sequences.

How to Run ?

1. Download "simple-dna-analyzer.py".
2. Run it using Python 3.
3. Enter a DNA sequence containing A, T, G, and C.

Concepts Used:

- Variables and lists
- Flag variables using Boolean values ("True" and "False")
- "while" and "for" loops
- "if-elif-else" conditions
- "break" statement
- String methods: "upper()" and "count()"
- "len()" and basic arithmetic

Learning Goal

This project was created to practise Python fundamentals through a simple bioinformatics application.
